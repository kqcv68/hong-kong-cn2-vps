## 建站配置速查：内存、CPU、带宽够不够用

### 内存怎么选

1GB内存只适合轻量单站、测试站，或者深度优化的WordPress（不装重型插件、不上宝塔面板、配Swap）。建议装LNMP一键包（如lnmp.org）而不是宝塔，省内存。

2GB内存是普通单个WordPress站点的舒适区。装宝塔面板 + LNMP环境 + 一两个常用插件，跑起来不卡。但宝塔会多占300-500MB内存，如果内存紧张还是选LNMP。

4GB内存能扛多站点、流量稍大的站点、或者WooCommerce电商站。可以装宝塔 + Redis对象缓存，后台并发请求处理更顺。

8GB及以上适合高流量站、多站点群、或者要跑Redis/Memcached对象缓存的进阶场景。

### CPU够不够

1核能跑WordPress，但2核是建站的舒适起点——后台并发请求、数据库查询、PHP处理都会更顺。如果你的站点会有突发流量（被转发、上热搜），2核以上能降低卡顿风险。

4核以上适合多站点、电商站、或者要跑多个服务（站点 + API + 数据库）的场景。

### 带宽和流量

香港VPS的带宽普遍10-30Mbps，对中小型站点完全够用。建站初期不必追求大带宽，但如果站点有大量图片、视频等资源，建议接Cloudflare等CDN，既能降低流量消耗，也能加速全球访问。

流量方面，纯文字博客200GB够用；如果有图片、视频，500GB起步更稳；WooCommerce电商站或者外贸独立站，建议1TB以上。

### 硬盘空间

20GB起步够用，但建议40GB以上留出日志和备份空间。WordPress本体 + 主题 + 插件一般不超过5GB，但数据库、日志、备份会不断增长，20GB很快就满。
